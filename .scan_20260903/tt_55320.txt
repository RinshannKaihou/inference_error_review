### 55320 [closed] ttnn.xlogy(0, y) returns NaN for y <= 0 where the convention is 0: the NaN guard inspects only the second operand
### Summary

`ttnn.xlogy(0, y)` returns `NaN` for `y <= 0`, where the defining convention of the function is that it returns `0` whenever `x == 0`, for every `y`. The kernel's NaN branch inspects only the second operand, so the `x == 0` case never gets a chance to short-circuit.

This is the case that matters in practice: `xlogy` exists precisely so that `0 * log(0)` evaluates to `0` in cross-entropy and KL-divergence, where a zero target against a zero or negative prediction is routine. Today a single such element turns the whole loss into `NaN`.

### Measured

On **ttsim** (tenstorrent/ttsim v1.10.3, `libttsim_bh.so`, Blackhole) with the prebuilt tt-metal `v0.79.0-dev20260902` ubuntu22.04 debs and SFPI 7.72.0, FLOAT32 in/out:

```
ttnn.xlogy(0.0,  0.0)  -> nan     torch.xlogy(0.0,  0.0)  -> 0.0
ttnn.xlogy(0.0, -1.0)  -> nan     torch.xlogy(0.0, -1.0)  -> 0.0
```

`scipy.special.xlogy` and `torch.xlogy` agree: the result is `0` whenever `x == 0`, including `y = 0`, `y < 0` and `y = NaN`.

### Cause

`tt_metal/hw/ckernels/blackhole/metal/llk_api/llk_sfpu/ckernel_sfpu_binary.h:126-133`:

```cpp
} else if constexpr (BINOP == BinaryOp::XLOGY) {
    v_if((in1 < 0.0f) || (in1 == nan)) { result = nan; }
    v_else {
        sfpi::dst_reg[dst_index_out * dst_tile_size_sfpi] = in1;
        _calculate_log_body_<false>(0, dst_index_out);
        result = sfpi::dst_reg[dst_index_out * dst_tile_size_sfpi] * in0;
    }
    v_endif;
}
```

The guard tests `in1` only. Two separate paths then produce `NaN` for `x == 0`:

- `xlogy(0, -1)`: `in1 < 0` is true, so the NaN branch is taken regardless of `in0`.
- `xlogy(0, 0)`: `in1 < 0` is false, so the else branch runs `log(0) = -inf`, and `-inf * 0 = NaN`.

The Wormhole copy has the same structure.

### Fix

Short-circuit on the first operand before either path, which is one predicate:

```cpp
} else if constexpr (BINOP == BinaryOp::XLOGY) {
    v_if(in0 == 0.0f) { result = 0.0f; }
    v_elseif((in1 < 0.0f) || (in1 == nan)) { result = nan; }
    v_else {
        ...unchanged...
    }
    v_endif;
}
```
