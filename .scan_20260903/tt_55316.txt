### 55316 [closed] ttnn.xlogy_bw and ttnn.addcdiv_bw hard-code the sign of the infinity at a zero divisor and skip the NaN case
**Component / Area:** ttnn eltwise binary/ternary backward (composite), `xlogy_bw`, `addcdiv_bw`

**Issue Type:** Bad Outputs

## Summary

Both ops special-case a zero divisor with a constant-sign infinity instead of the sign of the actual quotient, and `xlogy_bw` omits the `x == 0` NaN arm entirely.

`xlogy_bw`, gradient with respect to `other`
([binary_backward.cpp#L295-L306](https://github.com/tenstorrent/tt-metal/blob/9fa00fce13cda1538f0130695576408ff5b05665/ttnn/cpp/ttnn/operations/eltwise/binary_backward/binary_backward.cpp#L295-L306)):

```cpp
grad2 = grad * input_a * reciprocal(other);
grad2 = where(eqz(other), sign(grad) * inf, grad2);   // ignores sign(input_a); no NaN arm for input_a == 0
```

Torch's derivative is `grad * self / other`, so at `other == 0` the sign is `sign(grad * self)` and the value is NaN when `self == 0`.

`addcdiv_bw`, gradients with respect to `tensor1` and `tensor2`
([ternary_backward.cpp#L52-L76](https://github.com/tenstorrent/tt-metal/blob/9fa00fce13cda1538f0130695576408ff5b05665/ttnn/cpp/ttnn/operations/eltwise/ternary_backward/ternary_backward.cpp#L52-L76)):

```cpp
grad_a = grad * value * reciprocal(tensor2);
where(eqz(tensor2), where(eqz(grad), nan, +inf), grad_a)      // ignores sign(grad) and sign(value)
grad_b = (-grad * value * tensor1) * reciprocal(square(tensor2));
where(eqz(tensor2), where(eqz(grad), nan, -inf), grad_b)      // ignores sign(grad * value * tensor1); no NaN for tensor1 == 0
```

Torch: `tensor1: grad * value / tensor2` and `tensor2: -grad * value * tensor1 / tensor2^2`, signed by the full product, NaN when the numerator is zero.

`div_bw` in the same file already does this correctly
([binary_backward.cpp#L723-L740](https://github.com/tenstorrent/tt-metal/blob/9fa00fce13cda1538f0130695576408ff5b05665/ttnn/cpp/ttnn/operations/eltwise/binary_backward/binary_backward.cpp#L723-L740)):
`sign(input_a) * neg_inf * sign(grad)` with a NaN arm for `input_a == 0`. These two ops predate that fix and were never aligned.

This is a source-level analysis with a host replay; I do not have a card. The `where`/`sign` chain is exact, so the device result at a zero divisor is the constant the code selects.
