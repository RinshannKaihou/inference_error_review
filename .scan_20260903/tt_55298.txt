### 55298 [open] ttnn.unary_chain silently drops every op after the first when the head op uses a specialised kernel — hardswish→square returns unsquared hardswish
### Summary

`ttnn.unary_chain` silently drops every operation after the first when the first op is one that dispatches to a specialised compute kernel. The result is the head operation alone, with no error.

Measured on **ttsim** (tenstorrent/ttsim v1.10.3, `libttsim_bh.so`, Blackhole) with the prebuilt tt-metal `v0.79.0-dev20260902` ubuntu22.04 debs and SFPI 7.72.0. No hardware is required to reproduce:

```python
x  = ttnn.from_torch(torch.full((1,1,32,32), -1.0), dtype=ttnn.bfloat16,
                     device=d, layout=ttnn.TILE_LAYOUT)
ch = [ttnn.UnaryWithParam(ttnn.UnaryOpType.HARDSWISH),
      ttnn.UnaryWithParam(ttnn.UnaryOpType.SQUARE)]
ttnn.unary_chain(x, ch)   -> -0.33203125
```

`hardswish(-1.0) = -0.33333`, and squaring it gives `+0.11111`. The returned value is the hardswish result unsquared — and negative, so the `SQUARE` plainly never ran.

### Cause

`get_compute_kernel_path` selects the compute kernel from the **head op alone** (`ttnn/cpp/ttnn/operations/eltwise/unary/common/unary_op_utils.cpp:1172-1188`):

```cpp
std::string_view get_compute_kernel_path(UnaryOpType op_type, std::optional<DataType> input_dtype) {
    switch (op_type) {
        case UnaryOpType::LGAMMA: ... return "lgamma_fast_kernel.cpp" / "lgamma_kernel.cpp";
        case UnaryOpType::IDENTITY:  return "eltwise_identity_kernel.cpp";
        case UnaryOpType::WHERE_TSS: return "where_tss_kernel.cpp";
        case UnaryOpType::MAC_TSS:   return "mac_tss_kernel.cpp";
        case UnaryOpType::LOGIT:     return "logit_kernel.cpp";
        case UnaryOpType::HARDSWISH: return "hardswish_kernel.cpp";
        case UnaryOpType::LOGSIGMOID:return "logsigmoid_kernel.cpp";
        default: return "eltwise_sfpu.cpp";
    }
}
```

It has no visibility of `ops_chain.size()`. The generic kernel expands the rest of the chain, `device/kernels/compute/eltwise_sfpu.cpp:36-37`:

```cpp

#endif
```
