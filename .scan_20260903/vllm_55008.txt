## Describe the bug

### Reproduction

Run inside a pre-initialized 32-GPU multi-node launcher:

```bash
vllm serve nvidia/Qwen3.8-2.4T-A95B-NVFP4 \
  --served-model-name Qwen3.8-2.4T-A95B-NVFP4 \
  --trust-remote-code \
  --load-format fastsafetensors \
  --safetensors-load-strategy lazy \
  --gpu-memory-utilization 0.9 \
  --linear-backend auto \
  --moe-backend auto \
  --no-enable-prefix-caching \
  --tensor-parallel-size 16 \
  --pipeline-parallel-size 2 \
  --max-num-seqs 64 \
  --max-num-batched-tokens 8192 \
  --max-model-len 2200 \
  --kv-cache-dtype fp8 \
  --block-size 128 \
  --reasoning-parser qwen3 \
  --compilation-config '{"cudagraph_capture_sizes":[1,2,4,8,16,32,64],"inductor_compile_config":{"enable_auto_functionalized_v2":true}}'
```

Omission of `--enforce-eager` is intentional. The failure occurs during the compiled profile run before readiness.

With automatic linear-backend selection on A100, vLLM selects:

```text

```
