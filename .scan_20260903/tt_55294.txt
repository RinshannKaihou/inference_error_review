### 55294 [closed] ttnn.div and div_no_nan return NaN for every subnormal denominator; div(x,x) is NaN instead of 1
**Component / Area:** ttnn eltwise binary / SFPU LLK (`ckernel_sfpu_binary.h`, `ckernel_sfpu_recip.h`, WH B0 + BH)

**Issue Type:** Bad Outputs

## Summary

`ttnn.div(a, b)` returns `NaN` for every subnormal `b`, whatever `a` is. `div(x, x)` returns
`NaN` instead of `1` there. `ttnn.div_no_nan(0, b)` — an operation whose contract is its name —
also returns `NaN`.

The quotient is an ordinary number in every case below: `1`, `2`, `-1`, `0.5`. Nothing about the
result is near a representable limit; only the intermediate is.

This is the small-exponent mirror of **#52094** (`div` returns `0` for `|b| >= 2^126`). Same
kernel, same `a * (1/b)` evaluation strategy, opposite end of the exponent range. PR #52340
fixes only the large end, and only for Wormhole.

## Measured

ttsim v1.10.1, `Arch.BLACKHOLE`, ttnn 0.77.0, 32x32 tile, `ttnn.div` called directly.

| a | b | ttnn.div | torch.div |
|---|---|---|---|
| 5.877472e-39 | 5.877472e-39 | **nan** | 1.0 |
| 1.175494e-38 | 5.877472e-39 | **inf** | 2.0 |
| -5.877472e-39 | 5.877472e-39 | **nan** | -1.0 |
| 1.0 | 5.877472e-39 | **inf** | 1.7014118346046923e+38 |
| 1.175494e-38 | 1.175494e-38 | 1.0 | 1.0 (ok) |
| 1.0 | 1.175494e-38 | 8.507059173023462e+37 | 8.507059173023462e+37 (ok) |

The last two rows are the control: the same ratios one binade higher are exact.

### The boundary is exact, and it is the normal/subnormal edge

```
b = 2^-125 = 2.350989e-38  (normal)     ->  div(b,b) = 1.0   ok
b = 2^-126 = 1.175494e-38  (normal)     ->  div(b,b) = 1.0   ok
b = 2^-127 = 5.877472e-39  (subnormal)  ->  div(b,b) = nan   fails
b = 2^-128 = 2.938736e-39  (subnormal)  ->  div(b,b) = nan   fails
```

Every `|b| < 2^-126` fails, down to `2^-149`. Reachable in `bfloat16` as well, which returns
`inf` rather than `nan` for `div(b, b)` — the same defect resolving differently.

### `div_no_nan` violates its own contract

| a | b | ttnn.div_no_nan | expected |
|---|---|---|---|
| 0.0 | 5.877472e-39 | **nan** | 0.0 |
| 1.0 | 5.877472e-39 | **inf** | 1.7014118346046923e+38 |
| 0.0 | 0.0 | 0.0 | 0.0 (ok) |
| 1.0 | 0.0 | 0.0 | 0.0 (ok) |

An exact zero divisor is handled; a divisor one binade smaller is not. `0 / b` is `0` for every
nonzero
