`paged|sdpa` silently computes non-causal attention on a standard forward
STATE: open
BODY:
Found while testing training and continuous batching on one weight copy (training forward on the same model a CB manager generates with). Filing separately because the failure is silent and can bite anyone who runs a regular forward on a model with an attached CB manager.

### What happens

`ContinuousBatchingManager.switch_to_cb_friendly_attn` switches the whole model to a paged attention implementation. A standard forward in that state goes through `sdpa_attention_paged_forward`, which treats `cache` as optional (`kwargs.pop("cache", None)`) and runs plain SDPA when it is absent. But in paged mode the model builds no causal mask, so `attn_mask` is `None` and `is_causal` is never set: the forward is fully bidirectional. No error, no warning. (`paged|flash_attention_*` at least raises a `TypeError`, since `cache` is a
required positional there; `paged|eager` has the same silent problem as sdpa.)

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "Qwen/Qwen3-0.6B"
tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(
    model_id, dtype=torch.bfloat16, device_map="cuda:0", attn_implementation="sdpa"
)

batch = tokenizer(["The capital of France is Paris."], return_tensors="pt").to("cuda:0")
labels = batch["input_ids"].clone()

with torch.no_grad():
    ref_loss = model(**batch, labels=labels).loss.item()

model.set_attn_implementation("paged|sdpa")  # what the CB manager does to the model
with torch.no_grad():
    paged_loss = model(**batch, labels=labels).loss.item()  # expected: raise. actual: silent wrong result

print(f"sdpa loss:       {ref_loss:.4f}")
print(f"paged|sdpa loss: {paged_loss:.4f}")
assert abs(ref_loss - paged_loss) < 0.1, (
    "paged|sdpa silently computed different (non-causal) attention on a standard forward"
)
```
